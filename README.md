# Ender-3-NG-from-scratch
Bill of materials and build notes for a custom CoreXY 3D printer (enclosed frame, direct drive, Klipper). Based on the original design by RH3D. STL files are not included; get them from the original Printables page: https://www.printables.com/model/922401-ender-3-ng-v12-corexy-conversion
